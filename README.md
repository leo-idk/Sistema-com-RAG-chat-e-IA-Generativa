# rag_chat_with_memory_cli

This terminal chatbot uses the GitHub Models API and a local text file to answer technical questions through a strict Retrieval-Augmented Generation (RAG) system. 

It maintains conversation history in a list for natural dialogue and runs an interactive loop until you type "exit".

How to Run:

Install Python and the OpenAI library, then run python CLI_version.py (or whatever filename) in your terminal.

Enter your GitHub Models developer token when prompted, and the script will automatically load the local database file from the same directory to start the session.
